# Munk's Guide for the Perplexed

A scholarly digital parallel reader for Moses Maimonides' (*Rambam*) *The Guide for the Perplexed* (*Dalalat al-Ha'irin* / *Moreh Nevukhim*).

## Editions & Translations

- **English Translation & Annotations:** AI-assisted translation of Salomon Munk's 1856 French translation and critical notes (*Le Guide des Égarés*).
- **Hebrew - Makbili Edition:** Mif'al Mishneh Torah (2024), edited by Dr. Michael Makbili (via [Sefaria](https://www.sefaria.org/Guide_for_the_Perplexed)).
- **Hebrew - Samuel ibn Tibbon Translation:** Classic medieval Hebrew translation (via [Sefaria](https://www.sefaria.org/Guide_for_the_Perplexed)).
- **Hebrew - Rabbi Yosef Qafih Translation:** Modern Hebrew translation and explanatory notes by Rabbi Yosef Qafih (via [Daat](https://www.daat.ac.il/daat/mahshevt/more/shaar-2.htm), Machon Daat).
- **French Translation & Scholarly Notes:** Salomon Munk (1856–1866) via Sefaria.
- **Judeo-Arabic Source:** Original text of Maimonides.
